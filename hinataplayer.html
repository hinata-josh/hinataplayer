⚙️ 設定

瀏覽器端不能用桌面型憑證，要自己開一個「網頁應用程式」型 OAuth 用戶端：

  1. 到 Google Cloud Console → 憑證
  2. 啟用 Google Drive API
  3. 建立憑證 → OAuth 用戶端 ID → 類型「網頁應用程式」
  4. 「已授權的 JavaScript 來源」加入本頁 origin：
  5. 同意畫面若是「測試中」，把自己的帳號加進測試使用者
Drive 音檔快取上限（MB）— 超過就丟掉最舊的
